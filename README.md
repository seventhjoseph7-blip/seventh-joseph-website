# Seventh Joseph — AI Admin & Finance Automation

Website jasa otomasi AI untuk pekerjaan administrasi dan keuangan yang berulang (UMKM, startup, dan perusahaan asing di Indonesia).

- `index.html` — Bahasa Indonesia (utama)
- `en/index.html` — English
- `assets/site.css`, `assets/site.js` — gaya dan perilaku bersama (menu, kalkulator biaya, form WhatsApp/Email)
- `sitemap.xml` — daftar halaman untuk Google
